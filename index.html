📋 الوصف

متجر إلكتروني متكامل مع عرض المنتجات، سلة مشتريات، خصم تلقائي 15% عند الشراء بأكثر من 3000 جنيه، وإدارة المخزون.

✨ المميزات المطلوبة

  • عرض المنتجات المتاحة مع المخزون
  • نظام شراء ذكي (يخصم من المخزون)
  • سلة مشتريات تفاعلية
  • خصم 15% تلقائي عند تجاوز 3000 جنيه
  • حفظ البيانات في ملف JSON
  • حفظ الفواتير
  • واجهة منظمة مع قائمة خيارات

🛠️ الأدوات المطلوبة

Dictionaries Lists Functions Files (JSON) try/except if/elif/else while loop datetime

💡 كود الخصم التلقائي المطلوب

# نظام الخصم الذكي subtotal = sum(item["total"] for item in cart) # خصم 15% تلقائي عند الشراء بأكثر من 3000 if subtotal > 3000: discount = subtotal * 0.15 print(f"🎉 خصم 15%: -{discount:,.0f} جنيه") else: discount = 0 print("💡 أضف لأكثر من 3000 للحصول على خصم 15%!") total = subtotal - discount print(f"💰 الإجمالي: {total:,.0f} جنيه")
